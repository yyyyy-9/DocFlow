# Changelog

## 0.1.2 (local preparation)

Bridge 0.4.3 adds native Word hyperlink import/export and target-aware round trips. The shared Forms0.1.6 kernel gains hyperlink range facts and fidelity checks; metadata is generated from BUILD_INFO. UI0.1.2, template tool1.0.3 and the fixed HRS submodule remain unchanged. Separate Bridge packages declare their newer HRS App input explicitly; no public release or submodule update is implied.

## 0.1.1

Use generic Office author-metadata validation in the publication audit. Processing components and their document behavior are unchanged.

## 0.1.0

Initial public DocFlow suite: UI 0.1.2, Bridge 0.4.2, Forms 0.1.6 / kernel protocol 0.5.7, template style tool 1.0.3 and pinned HRS 2.0.0.

One shared Forms source tree serves UI, Excel and Bridge. Public-only documentation, a generic cover template, reproducible synthetic fixtures, explicit dependency groups and a unified source/release manifest accompany the existing processing engines.
