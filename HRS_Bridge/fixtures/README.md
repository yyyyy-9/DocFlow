# Public synthetic fixtures

- public_source/report.md and its geometry assets are authored for this repository under GPL-3.0-or-later. PNG images and EMF drawings contain only geometric shapes; no photographs, screenshots or external reports are used.
- hrs_sample.html is generated by the original HRS exporter and ignored by Git. Run tools/create_public_fixture.py --archive with the browser dependency installed.
- target_template.docx is the generic report style template. wps_sample.docx is a synthetic heading/list/figure/table/math demonstration, with empty personal metadata.
- cover_template_v0311.docx is the published project-owned generic cover/TOC/header example from HRS/template-tool.

No file here represents measurements, user content or evaluation answers. Preserve the unknown-content rejection tests; do not replace them with fixed screenshots or relax hashes to pass a fixture.
